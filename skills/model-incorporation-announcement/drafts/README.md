# Drafts

`/model-incorporation-announcement` writes each announcement here as
`YY-MM-DD-<eosXXXX>.md`.

A file in this folder is **an unpublished draft**, not a record of something posted. It
holds the post body and the profile-tagging worksheet, and nothing else — the skill's whole
deliverable is one LinkedIn post. Keeping them means the next announcement can be written
against the last one — the hooks in particular get better by comparison — and that a post
which drew a reaction can be traced back to exactly what was drafted and which profiles
were verified.

The profile rows record whether a LinkedIn profile was **confirmed** or **unverified**.
Never promote a row to confirmed without re-checking it; verification does not age well.
