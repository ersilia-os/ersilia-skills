# Ersilia strategic priorities — the relevance rubric

Use this file in Step 4 (screen for relevance) and Step 5 (priority scoring). An
event stays in the report only if it maps to **at least one** of the four strategic
priorities below. If it maps to none, drop it.

Source: `config/CLAUDE.md` ("Strategic priorities"). Keep this file in sync if that
file changes.

## The four strategic priorities

1. **Build the reference resource for AI/ML in infectious-disease research.**
   Grow the Ersilia Model Hub into the largest platform for AI-driven antibiotic
   discovery; run large-scale chemical-space pre-calculations.
   → *Events that fit:* cheminformatics, AI/ML for chemistry and drug discovery,
   model/dataset/benchmark venues, open-source scientific tooling.

2. **Pursue novel therapeutic opportunities for understudied diseases.**
   New modalities (e.g. targeted protein degradation); AI-first target discovery for
   orphan neglected tropical diseases; natural-product-like chemical space.
   → *Events that fit:* infectious- and neglected-disease drug discovery, medicinal
   chemistry, target biology for priority pathogens.

3. **Provide long-term training in the Global South.**
   In-person workshops in Africa; an AI Incubator cohort; internships for
   underrepresented students.
   → *Events that fit:* capacity-building schools, summer courses, and workshops —
   especially those hosted in or serving low- and lower-middle-income countries
   (LMICs; see `lmic-countries.md`).

4. **Build the community that makes the work sustainable.**
   Long-term partnerships with Global-South research institutions; presence in
   Barcelona, Catalonia and Europe; diversified funding.
   → *Events that fit:* open-source and open-science community gatherings, networking
   with partners and funders, philanthropy/foundation forums.

## Priority organisms and disease areas (for relevance judgement)

- **Priority pathogens:** *M. tuberculosis* / *M. abscessus*, *P. falciparum* /
  *P. vivax*, *Leishmania* spp., *T. cruzi* / *T. brucei*, *S. mansoni*, plus ESKAPE
  and WHO GLASS antimicrobial-resistance (AMR) priority pathogens.
- **Method areas:** QSAR, graph neural networks, molecular representation /
  featurization, generative chemistry, ADMET and bioactivity prediction, foundation
  models for chemistry.
- **Cross-cutting framing:** open source, reproducibility, low-data / few-shot
  learning, and tools usable in resource-limited settings.

## Priority scoring rubric (Step 5)

Assign each surviving event **High / Medium / Low** by combining three signals.
Do not over-think it — pick the label the majority of signals support.

| Signal | Points toward higher priority |
|---|---|
| **Strategic fit** | Maps to ≥2 priorities, or squarely to priority 1 or 3, → higher. Tangential single-priority fit → lower. |
| **Global-South relevance** | Hosted in or explicitly serving LMICs, or with travel-support / open access → higher (this is the 🌍 lens; see `lmic-countries.md`). |
| **Reachability** | Free / virtual / low-cost / has a bursary, or in Europe (easy from Barcelona) → higher. Expensive and far with no support → lower. |

- **High** — strong fit to a core priority *and* either Global-South relevance or clear
  reachability; something the team should actively attend, apply to, or partner on.
- **Medium** — a real fit but with a caveat (cost, distance, tangential theme).
- **Low** — relevant enough to note, but a "watch / maybe" rather than an action.

State the mapped priority (by number) and a recommended **action** — *attend / apply /
partner / watch* — in each event's one-line justification.
