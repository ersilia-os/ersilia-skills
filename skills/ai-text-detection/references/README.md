# references/

Data the scripts read, and the documents behind them. Rule of thumb: change data here
before changing code (SKILL.md, step 7), and never hand-edit a generated file.

## Read by people

| File | What |
|---|---|
| `methods.md` | What each check measures, how strong it is, and the sources: for explaining a finding to an editor or programme officer |
| `web-detectors.md` | How to run the web detectors: confidentiality, splits, browser and API routes, site rules |
| `watermarks.md` | Provider watermarks (Claude, ChatGPT): who can verify, and what a result shows |
| `validation.md` | Style score: false-positive and detection rates on held-out text (generated by `calibrate.py`) |
| `web_validation.md` | Web detectors: false alarms, detection rates and likelihood ratios on known texts (generated by `web_controls.py analyze`) |

## Hand-curated data (change through the Learn step, then run `selftest.py`)

| File | What |
|---|---|
| `markers.json` | Artefact patterns: regex, tier, category, source, positive and negative examples |
| `tortured_phrases.json` | Paraphraser fingerprints ("profound learning" for "deep learning") |
| `excess_words.csv` | Excess vocabulary after ChatGPT (Kobak et al. 2025, MIT licence) |
| `grading.json` | Every threshold `grade.py` uses to set the tier |
| `web_detectors.json` | Each web detector: URL, size limits, parser, terms, cookie rule, published evidence, automation status |
| `policies.json` | Journal, funder and reviewer policies on AI use, with sources (summaries) |
| `watchlist.json` | What the monthly scan (`watch.py`) looks for, and what it found |
| `feedback-log.json` | The user's lessons and what changed because of each (`record_feedback.py`) |

## Generated (re-run the script; do not edit)

| File | Written by |
|---|---|
| `calibration.json` | `calibrate.py`: style-score model and thresholds |
| `web_calibration.json` | `web_controls.py analyze`: per-detector rates on known texts |
| `calibration/human.jsonl` | `build_corpus.py`: 1,115 windows of published human text, 2015–2021 |
| `calibration/ai.jsonl`, `polished.jsonl` | Written for this repository, plus RAID rows; see `calibration/SOURCES.md` |

Nothing here comes from a user's document. Case data stays in `~/.ai-text-detection/` (numbers only).
